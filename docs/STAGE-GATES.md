## Progression rule

A route existing or rendering is not a gate. Before moving on, the current stage must be built/designed as specified, functional with realistic data, responsive, state-complete, accessible, tested where applicable, visually reviewed, and free of known critical defects. If a gate fails, fix it in place and rerun the relevant verification.
